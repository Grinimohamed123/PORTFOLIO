# Portfolio - Mohamed Grini

Portfolio web d'un **Coordinateur BIM TCE & Manager de synthese**, specialise
dans les mega-projets hospitaliers (coordination tous corps d'etat, detection
de clashs, fluides medicaux).

Site statique : une seule page HTML, sans dependance ni build.

## Apercu

- `index.html` - la page (HTML + CSS + un peu de JS, tout dans un seul fichier)
- `images/` - les visuels des projets

## Voir en local

Ouvrir `index.html` dans un navigateur. C'est tout.

## Mettre en ligne (GitHub Pages)

1. Depot GitHub > onglet **Settings** > **Pages**
2. *Source* : `Deploy from a branch`
3. *Branch* : `main` / `/ (root)` > **Save**
4. Au bout d'une minute, le site est en ligne sur
   `https://<utilisateur>.github.io/portfolio-bim/`
